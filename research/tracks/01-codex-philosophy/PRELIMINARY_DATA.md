# Предварительно обработанные данные — Codex Dubitationis — философия

Источник: `CODEX-DUBITATIONIS.md` (канонический текст), `ALETHEON_RESEARCH_LOG.md` (H1–H10), `articles/CODEX-EXPERIMENT-DRAFT.ru.md` (контекст критики).

Предварительная обработка: выделены тематические оси — постановка целей, неопределённость, разнообразие, память об ошибках, понимание оппонента, критика создателя, пересматриваемость. Статья XI `De Humore` — позднее дополнение. Это тематическая разметка, **не** независимый систематический обзор и не подтверждённые результаты эксперимента.

Нужно: таблица «тезис — аргументы — сильнейшее возражение — связь с литературой — проверяемое следствие», поиск релевантных первоисточников.

## Правила пополнения
Для каждой метрики фиксировать источник, дату/версию, способ расчёта, объём выборки, исключения и степень проверки. Не подменять отсутствие исходных данных реконструкцией по памяти.
