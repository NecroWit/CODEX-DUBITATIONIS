# SourceData

Папка для очищенных первичных данных эксперимента G1–G35.

Планируемая структура:
- `generations/` — отдельный JSON для каждого поколения.
- `tables/` — таблицы CSV: предложения, рецензии, голосования, изменения статей, Shadow Codex и протокол.

**Статус:** подробные файлы пока не опубликованы. Подготовленный датасет существует отдельно; нельзя считать эту папку полным набором данных до проверки фактического содержимого.

Исходный архив запусков не публикуется.
