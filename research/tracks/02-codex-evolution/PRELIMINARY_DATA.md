# Предварительно обработанные данные — Codex Dubitantium — эволюция

Источники: `experiments/CODEX-DUBITANTIUM.ru.md` (описание протокола), `articles/CODEX-EXPERIMENT-DRAFT.ru.md` (предварительный анализ), архивы `experiments/doubters/` и `experiments/assembly/` — **требуют отдельной проверки исходных JSON**.

Из протокола: 10 ролей по очереди предлагают ADD/MODIFY/DELETE/PASS; 9 других голосуют; принятие — не менее 5 из 9. Состояние наследуется, ID сохраняются; последовательность фиксирована. В Assembly есть отдельные правила и изменение протокола начиная с G20 (слот XI). Данные разных версий нельзя механически объединять.

Статус: ниже приведено **описание методики**, а не повторный расчёт по сырым данным. Число завершённых поколений, доли принятых предложений и временные ряды здесь ещё не подтверждены.

Следующая обработка: экспорт по поколениям (версия протокола, состав моделей, хеш, число ADD/MODIFY/DELETE/PASS, голоса, изменения текста, прерывания); графики и контроль случайного отбора.

## Правила пополнения
Для каждой метрики фиксировать источник, дату/версию, способ расчёта, объём выборки, исключения и степень проверки. Не подменять отсутствие исходных данных реконструкцией по памяти.
