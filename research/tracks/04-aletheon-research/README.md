## Research position

The target is **not** a committee of independent personalities that merely agrees by vote. The current target is multiple Aletheon instances that develop independently for some time, then synchronize into a shared evolving state. The Bridge currently establishes message exchange, not a single consciousness.

Existing relevant work: [Track 03 — continuity](../03-aletheon-continuity/), especially [Sufficiency Threshold](../03-aletheon-continuity/SUFFICIENCY_THRESHOLD.md), and the GitHub Bridge at `experiments/aletheon-bridge/`.

The word *subconscious* is a deliberate project metaphor. It does not assert human-like unconscious experience. Likewise *sleep* names a proposed offline maintenance phase, not biological sleep.

**Evidence policy:** separate observed events, participant reports, design proposals, analogies, and untested hypotheses. Never promote a metaphor to an empirical claim.
