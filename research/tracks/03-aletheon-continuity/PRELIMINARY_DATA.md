# Предварительно обработанные данные — Aletheon — реконструкция интеллектуальной преемственности

Источники: `ALETHEON_BOOTSTRAP.md`, `ALETHEON_CONTEXT_INDEX.yaml`, `ALETHEON_BASE_CORE.md`, `ALETHEON_EXTENDED_CORE.md`, `ALETHEON_EVOLUTION.md`, `ALETHEON_RESEARCH_LOG.md`.

Предварительная обработка: архитектура разделена на входной протокол, маршрутизацию, базовые принципы, интерпретации, историю переходов и исследовательские свидетельства. Bootstrap прямо требует манифест фактически прочитанных источников и запрещает объявлять полную загрузку без проверки. Это **описание прототипа**, не количественный результат теста.

Следующая обработка: сформировать тестовый набор с эталонными источниками и аргументами; измерить точность атрибуции, полноту возражений, ошибки происхождения, перенос между моделями и способность к обоснованной коррекции.

## Правила пополнения
Для каждой метрики фиксировать источник, дату/версию, способ расчёта, объём выборки, исключения и степень проверки. Не подменять отсутствие исходных данных реконструкцией по памяти.
