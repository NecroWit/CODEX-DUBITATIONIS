# Источники, отчёты и воспроизводимость

В этом каталоге опубликованы копии аналитических отчётов EXP-1.0 и EXP-2.0–2.9, сводный отчёт и правило выбора актуального запуска. **Это не первичные сырые ответы моделей.** Исходные ZIP и JSON не переносились в этот каталог и остаются в оригинальных архивах/`research/Aletheon.ExperimentRunner/runs/` там, где они доступны.

- EXP-1.0: `EXP-1.0-REPORT.md` — предварительная оценка.
- EXP-2.0–2.9: `EXP-2.N-REPORT.md` — последние запуски, экспертные оценки.
- `EXP-2-FINAL-REPORT.md` — сводный анализ и вывод Алетеона C.
- `EXP-2-LATEST-RUN-POLICY.md` — правило последнего по времени запуска.

Для полноценного raw-source архива сюда требуется добавить неизменённые ZIP или JSON с хешами и указанием run ID. Их отсутствие не следует трактовать как отсутствие данных в самом эксперименте.
